### 🧠 **What's Inside this Repository?**

Welcome to a collection of machine learning algorithms, statistical models, and data exploration tools. Below is the map to navigate this digital labyrinth:

| 🔮 **Script** | 📜 **Description** |
|:---|:---|
| 🧮 `calculator.py` | Basic algebraic operations simulator. |
| ➕ `add_function.py` | Functional syntax exploration. |
| 📦 `class_example.py` | Object-oriented programming blueprint. |
| 🔄 `loops_demo.py` & `while_loop.py` | Infinite loop paradigms. |
| ⚖️ `compare_numbers.py` | Logical comparison algorithms. |
| 📊 `pandas_dataframe.py` | Dataframe manipulation and synthesis. |
| 📈 `placement_eda.py` | Exploratory Data Analysis & visual mapping. |
| 📉 `linear_regression.py` | Baseline predictive modeling on California Housing. |
| 📏 `simple_linear_regression.py` | A foundational 1D linear regression. |
| 🕸️ `regularization_models.py` | Ridge, Lasso, and ElasticNet models for feature shrinking. |
| 🌲 `decision_trees.py` | Branching logic models (Gini, Entropy, Cost Complexity Pruning). |
